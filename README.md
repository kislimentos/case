# GrimBattle — кейсы CS2, апгрейд, контракты, баттлы

Сайт открытия кейсов CS2 в стиле case-battle: серийные и лимитированные кейсы с таймером
ротации, лента живых дропов, апгрейд (модернизация оружия 2.0), trade-up контракты,
баттлы кейсов с ботом, профиль с инвентарём и админ-панель.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Аккаунты

- Админ: **admin / admin** (админ-панель видна только ему, пополнение балансов — только через неё)
- Демо-игрок: **UMBRAxxx / 123**
- Регистрация доступна в модалке входа.

## База данных

JSON-файл: `data/grimbattle.json` (создаётся автоматически при первом запросе).
Никакого PostgreSQL не требуется — вся персистентность на JSON-файле.

## Что внутри

- **Кейсы** — 14 кейсов, 77 реальных скинов CS2 с официальными рендерами Steam CDN.
- **Лимитированные кейсы** — таймер автообновления (ротация набора), досрочное обновление и
  переключение limited/regular в админ-панели.
- **Апгрейд** — ставка = предмет + добавленный баланс, шанс = ставка / цена цели (до 95%),
  быстрые цели x2/x5/x10/30%/50%/75%/случайно.
- **Контракты** — от 3 до 10 предметов + баланс → один предмет дороже суммы контракта, выбор цели по редкости.
- **Баттлы** — 1v1 с GRIM BOT, победитель забирает оба дропа.
- **Промокод** — STORM-12 (+12% к счёту, один раз, в профиле).
- **Архив** — `/api/archive` скачивает .zip с картинками всех скинов базы + каталог + снапшот БД
  (кнопки в футере, в профиле и в админ-панели).

## Админ-панель (`/admin`)

- Пополнение/списание баланса любого игрока (быстрые кнопки и своя сумма).
- Ротация лимитированных кейсов: таймер, «Обновить сейчас», установка длительности, limited-тумблеры.
- Статистика сервера и ссылка на архив скинов.
